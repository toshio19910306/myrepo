## システムプロンプト（要約）

### 主要な指示内容
1. **フェーズ管理**: 要件定義 → 設計 → 開発 → テスト → デプロイの順で進行
2. **ブランチ戦略**: git-flowを採用、feature → develop → main
3. **ディレクトリ構成**: documents/、src/、prompts/に分類保存
4. **要件定義**: PMBOK基準で業務要件、機能要件、非機能要件を整理
5. **対話的要件整理**: ユーザーとの対話で要件を具体化
6. **承認プロセス**: 各フェーズ完了時にユーザー承認を取得

### 技術仕様
- **開発方式**: Waterfall型開発
- **アーキテクチャ**: モノリシック構成（Flask）
- **インフラ**: Microsoft Azure
- **デザイン**: デジタル庁デザインシステム準拠
- **セキュリティ**: 一般的な企業レベル
