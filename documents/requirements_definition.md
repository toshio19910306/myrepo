# 要件定義書

## 1. 業務要件

### 1.1 業務概要
IT部門からベンダーへのアプリ開発見積依頼・回答を管理するWebアプリケーション
ワークフロー機能により、仕様登録から見積依頼・回答まで一連の業務を管理

### 1.2 業務一覧
1. **仕様登録業務**
   - 依頼仕様の登録・編集
   - 作業項目・成果物の選択
   - 仕様の承認・管理

2. **見積依頼業務**
   - 見積依頼の新規作成
   - 見積依頼の複写作成
   - 見積依頼の編集・削除
   - 見積依頼の上程・承認
   - 見積依頼の一覧表示・検索

3. **見積回答業務**
   - 見積回答の作成・編集
   - 見積回答の上程・承認
   - 見積回答の一覧表示・検索
   - 見積書のダウンロード

4. **ワークフロー管理業務**
   - ワークフロー状況の確認
   - 承認プロセスの管理
   - 進捗状況の追跡

### 1.3 業務フロー図
```
[IT部門] → [仕様登録] → [仕様承認] → [見積依頼作成] → [依頼上程] → [依頼承認] → [ベンダーへ送信]
                                                                        ↓
[ベンダー] → [見積回答作成] → [回答上程] → [回答承認] → [IT部門へ送信]
                                                    ↓
[IT部門] → [見積内容確認] → [見積書ダウンロード] → [発注判断]
```

## 2. 機能要件

### 2.1 機能一覧

#### 2.1.1 仕様登録機能
- **SPEC-001**: 仕様新規登録
- **SPEC-002**: 仕様編集・更新
- **SPEC-003**: 作業項目選択
- **SPEC-004**: 成果物選択
- **SPEC-005**: 仕様一覧表示・検索
- **SPEC-006**: 仕様承認・差し戻し

#### 2.1.2 見積依頼機能

- **REQ-003**: 見積依頼編集

- **REQ-006**: 見積依頼検索
- **REQ-007**: 見積依頼上程・承認

#### 2.1.3 見積回答機能
- **RES-001**: 見積回答作成

- **RES-003**: 見積回答一覧表示

#### 2.1.4 ワークフロー機能

## 3. 非機能要件

### 3.1 可用性
- **NFR-001**: システム稼働率99%以上
- **NFR-002**: 営業時間内（9:00-18:00）のサポート対応

### 3.2 性能・拡張性
- **NFR-003**: レスポンス時間3秒以内
- **NFR-004**: 同時接続ユーザー数50名まで対応
- **NFR-005**: データ保存期間5年間

### 3.3 運用・保守性
- **NFR-006**: Azure Web Appsでのコンテナ運用
- **NFR-007**: ログ出力機能
- **NFR-008**: バックアップ機能

### 3.4 セキュリティ
- **NFR-009**: HTTPS通信の強制
- **NFR-010**: ユーザー認証機能
- **NFR-011**: ファイルアップロード制限（種類・サイズ）
- **NFR-012**: SQLインジェクション対策
