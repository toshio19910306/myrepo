## 1. 機能概要

### 1.1 システム概要
経費申請から承認完了までの一連のプロセスをデジタル化し、効率的な業務運営を支援するWebアプリケーション。

### 1.2 主要機能
- 経費申請機能
- 承認・却下機能
- 申請状況確認機能
- ユーザー管理機能
- 通知機能
- レポート機能

## 4. 機能詳細仕様

### 4.1 経費申請登録機能（F002）

#### 4.1.1 機能概要
申請者が新規経費申請を登録する機能

#### 4.1.2 入力項目
| 項目名 | 必須 | 形式 | 備考 |
|--------|------|------|------|
| 申請日 | ○ | 日付 | システム日付がデフォルト |
| 申請タイトル | ○ | 文字列(50文字以内) | |
| 経費発生日 | ○ | 日付 | |
| 金額 | ○ | 数値 | 正の整数 |
| 用途 | ○ | 選択 | 交通費、会議費、備品費等 |
| 支払先 | ○ | 文字列(100文字以内) | |
| 備考 | | 文字列(500文字以内) | |
| 領収書 | ○ | ファイル | PDF、JPG、PNG形式 |

#### 4.1.3 処理フロー
1. 申請者が申請画面にアクセス
2. 必要項目を入力
3. 領収書ファイルをアップロード
4. 入力内容を確認
5. 申請を提出
6. 1次承認者に通知送信

#### 4.1.4 バリデーション
- 必須項目の入力チェック
- 金額の数値チェック
- ファイル形式・サイズチェック
- 日付の妥当性チェック

### 4.2 承認処理機能（F103）

#### 4.2.1 機能概要
承認者が申請を承認する機能

#### 4.2.2 入力項目
| 項目名 | 必須 | 形式 | 備考 |
|--------|------|------|------|
| 承認コメント | | 文字列(500文字以内) | |

#### 4.2.3 処理フロー
1. 承認者が承認待ち一覧から申請を選択
2. 申請詳細を確認
3. 承認コメントを入力（任意）
4. 承認ボタンをクリック
5. 承認処理実行
6. 申請者と次の承認者に通知送信

#### 4.2.4 承認段階別処理
- **1次承認**: 2次承認者に転送
- **2次承認**: 3次承認者に転送
- **3次承認**: 申請完了、経理処理へ

### 4.3 却下処理機能（F104）

#### 4.3.1 機能概要
承認者が申請を却下する機能

#### 4.3.2 入力項目
| 項目名 | 必須 | 形式 | 備考 |
|--------|------|------|------|
| 却下理由 | ○ | 文字列(500文字以内) | 必須入力 |

#### 4.3.3 処理フロー
1. 承認者が却下ボタンをクリック
2. 却下理由を入力
3. 却下処理実行
4. 申請者に通知送信
5. 申請ステータスを「却下」に更新

## 5. 画面遷移

### 5.1 申請者画面遷移
```
ログイン画面 → ダッシュボード → 申請一覧
                    ↓
                新規申請 → 申請確認 → 申請完了
                    ↓
                申請詳細 → 申請編集
```

### 5.2 承認者画面遷移
```
ログイン画面 → ダッシュボード → 承認待ち一覧
                    ↓
                申請詳細 → 承認/却下/差し戻し → 処理完了
```

### 5.3 管理者画面遷移
```
ログイン画面 → 管理ダッシュボード
                    ├── ユーザー管理
                    ├── 組織管理
                    ├── 承認フロー設定
                    └── レポート出力
```
