# 非機能要件定義書

## 可用性要件

### 1. システム稼働率
- **目標稼働率**: 99.5%（月間）
- **計画停止時間**: 月4時間以内
- **障害復旧時間**: 2時間以内

### 2. バックアップ・復旧
- **データバックアップ**: 日次自動バックアップ
- **バックアップ保存期間**: 30日間
- **復旧時間目標**: 1時間以内

### 3. 冗長化
- **データベース**: SQL Server Always On可用性グループ
- **アプリケーション**: Azure App Service複数インスタンス
- **ストレージ**: Azure Blob Storage（GRS）

## 性能・拡張性要件

### 1. 処理性能
- **バッチ処理時間**: 1万件あたり10分以内
- **同時接続数**: 最大50ユーザー
- **レスポンス時間**: 
  - 画面表示: 3秒以内
  - API応答: 1秒以内

### 2. スループット
- **データ処理量**: 1時間あたり最大10万件
- **ファイルサイズ**: 最大100MB
- **同時バッチ実行**: 最大3プロセス

### 3. 拡張性
- **水平スケーリング**: Azure App Service自動スケーリング
- **データベース拡張**: SQL Server読み取りレプリカ対応
- **ストレージ拡張**: Azure Blob Storage自動拡張

## 運用・保守性要件

### 1. 監視
- **システム監視**: Azure Monitor
- **アプリケーション監視**: Application Insights
- **データベース監視**: SQL Server Management Studio
- **ログ監視**: Azure Log Analytics

### 2. ログ管理
- **ログレベル**: ERROR, WARN, INFO, DEBUG
- **ログ保存期間**: 90日間
- **ログ形式**: JSON構造化ログ
- **ログ出力先**: Azure Log Analytics

### 3. アラート
- **エラー発生時**: 即座にメール通知
- **性能劣化時**: 閾値超過でアラート
- **ディスク使用量**: 80%超過でアラート

### 4. メンテナンス
- **定期メンテナンス**: 月1回（第3日曜日深夜）
- **緊急メンテナンス**: 必要に応じて実施
- **バージョンアップ**: 四半期ごと

## セキュリティ要件

### 1. 認証・認可
- **認証方式**: Azure Active Directory
- **多要素認証**: 必須
- **ロールベースアクセス制御**: RBAC実装
- **セッション管理**: 8時間自動ログアウト

### 2. データ保護
- **データ暗号化**: 
  - 保存時: AES-256
  - 転送時: TLS 1.3
- **個人情報保護**: マスキング機能
- **データ削除**: 論理削除＋物理削除

### 3. ネットワークセキュリティ
- **ファイアウォール**: Azure Firewall
- **VPN接続**: サイト間VPN
- **プライベートエンドポイント**: Azure Private Link
- **DDoS対策**: Azure DDoS Protection

### 4. 監査
- **アクセスログ**: 全操作記録
- **変更履歴**: データ変更追跡
- **監査レポート**: 月次レポート生成

## 互換性要件

### 1. ブラウザ対応
- **対応ブラウザ**: 
  - Chrome 最新版
  - Edge 最新版
  - Firefox 最新版
  - Safari 最新版

### 2. データベース
- **SQL Server**: 2019以降
- **互換性レベル**: 150以降

### 3. ファイル形式
- **CSV**: RFC 4180準拠
